# Nieve 3.1.3 → 3.1.7 更新日志汇总

面向用户的完整更新记录，覆盖 3.1.4、3.1.5、3.1.6、3.1.7 四个版本。
按「新增 / 优化 / 修复 / 说明」分类，每一条后面标注首次出现的版本。

---

## 新增

### 音乐播放

- **全屏播放页重排**（3.1.4）：封面缩到左上角，中间主体让给歌词；底部依次是进度条、
  上一曲 / 播放暂停 / 下一曲，以及「悬浮唱片旁显示歌词」开关。
- **歌词跟随与点击跳转**（3.1.4）：当前行自动居中并高亮，长句自动换行不截断；
  点击带时间轴的歌词行可以跳到对应时间。
- **悬浮唱片**（3.1.4）：离开音乐页后，播放中的歌收成左上角圆形唱片，封面构成、
  播放时旋转、暂停即停；可拖动并吸附边缘，旁边跟随当前一句歌词，点它回到播放页。
- **系统媒体控制与锁屏**（3.1.4）：通知栏 / 系统媒体栏 / 锁屏显示封面、歌名、歌手、
  播放暂停与上下曲，和 App 内状态双向同步；停止播放会释放会话，不留僵尸通知。
- **三种播放模式**（3.1.5）：单曲循环、列表循环、随机播放；播放页与系统通知都能切换，
  切歌逻辑跟随模式（随机不连续重复、列表到头回第一首、单曲循环只手动切）。
- **歌单**（3.1.5）：新建、重命名、删除、增删歌曲、调整顺序，本地持久化，重启不丢。
- **本地音乐**（3.1.5）：按文件夹或单曲导入设备音频，适配分区存储，不申请多余权限。
- **在线音乐入歌单 / 队列**（3.1.5）：在线曲目也能加入歌单与播放队列。

### 工具与界面

- **6 个实用小工具**（3.1.6）：Base64 编解码、摩斯电码、金额大写、时间戳转换、
  温度换算、特殊文字；均为纯本地计算，入口在「功能」页。
- **下载板块侧栏自动收起**（3.1.6）：进入下载页时左侧导航隐藏，内容占满宽度；
  从内容区右滑以悬浮层呼出，首次进入有一次手势引导。
- **启动读取剪贴板**（3.1.6）：每次打开 / 回到前台识别链接，弹窗提供「一键解析」；
  直链或磁力额外提供「直接下载」；同一链接按内容 hash 记忆，不重复打扰。
- **流畅模式（低端机）**（3.1.6，3.1.7 加强）：自动按 `isLowRamDevice` 判断，也可手动开关。
- **一起开发入口**（3.1.6 设置 / 关于，3.1.7 首页）：招募 Android / Compose 开发者，
  统一跳转酷安初雪主页。
- **VIP 解析进入提示**（3.1.6）：进入前明确告知「仅部分链接可用」，不再让用户误以为必成功。
- **自动领红包说明页**（3.1.6）：入口保留，但明确标注本期不再提供及原因。

## 优化

- **播放与切歌稳定性**（3.1.4）：自动连播、切歌解析、失败提示从页面级提升到应用级，
  离开音乐页仍然有效；歌词只请求一次，悬浮唱片与播放页共用同一份结果。
- **播放页适配**（3.1.4）：横屏改为左右分栏，竖屏上下堆叠；播放时临时隐藏底部导航，
  返回列表自动恢复。
- **通知与锁屏同步**（3.1.4 / 3.1.5）：封面写入 MediaMetadata，切歌 / 暂停实时刷新；
  通知栏模式按钮随播放模式切换更新。
- **红包链路排查**（3.1.6）：去掉「Shizuku 心跳生效时让无障碍让位」的判断，
  避免两边互相谦让导致都不工作；功能暂停后不再展示「已就绪 / 运行中」。
- **VIP 解析失败出口**（3.1.6）：播放失败页新增「浏览器打开」，可把当前线路交给系统浏览器。
- **冷启动与内存**（3.1.6）：同机对比，冷启动中位数从约 2.68s 降到约 2.49s，
  启动后 PSS 从约 210MB 降到约 208MB。
- **流畅模式加强**（3.1.7）：
  - 页面过渡在流畅模式下只保留 90ms 淡入淡出，关掉位移与缩放；
  - 悬浮唱片停止旋转，歌词 / 进度轮询从 400ms 放宽到 2000ms；
  - 封面按更小目标尺寸解码，图片内存缓存上限压到 10%（普通模式 25%）；
  - 隐藏 WebView 同一时刻只允许一个实例，流畅模式下不走 WebView 磁盘缓存；
  - 工具网格增加稳定 key，减少滚动时整块重组。
  - 同机页面切换帧数据（6 次切页）：流畅模式 7.75% Janky / 90th 16ms / 99th 125ms，
    关闭时 11.27% / 20ms / 150ms。属于同一台设备的对比，仍有系统波动。
- **首页信息结构**（3.1.7）：新增「参与开发」分组，把招募入口放到首页可见位置。

## 修复

- **前台再次打开指定工具只落到功能首页**（3.1.4）：修复 `initialToolRoute` 只读一次
  导致外部 intent / 媒体通知二次进入不生效的问题。
- **离开音乐页后自动连播失效 / 播放失败无提示**（3.1.4）：改为应用级控制器，
  失败时明确弹窗。
- **通知栏模式按钮导致 MediaSession 崩溃**（3.1.5）：给 media3 `CommandButton`
  补真实 `iconResId`，旧版控制器不再收到不支持的自定义命令。
- **本地音乐无权限 / 空列表提示误导**（3.1.5）：改为说明可直接导入，并给出导入入口；
  扫描为空明确提示「本地没有找到音乐文件」。
- **红包升级后静默失效**（3.1.6）：升级前开过开关的用户，进入说明页会看到
  「已为你关闭红包开关」，开关与通知跳转一并关闭。
- **剪贴板重复提示**（3.1.6）：启动弹窗与解析页原有提示共用同一份 hash 记忆，
  一次启动不会弹两遍。
- **VIP 解析无路可退**（3.1.6）：失败卡片增加「浏览器打开」，不再只能在 App 内反复换线路。

## 说明与限制

- **自动领红包：本期不再提供**（3.1.6 起）。微信对自动化点击有限制，无障碍服务能读到节点
  但经常点不动，改用 Shizuku（shell + UiAutomation）也一样；更换授权方式无法规避，
  开发者不再声称支持。入口保留为说明页，底层代码保留但标注「暂停 / 未启用」。
- **VIP 解析成功率无法保证**：依赖第三方线路，线路失效、防盗链、链接类型不支持都会失败；
  进入前会明确提示「仅部分链接可用」。
- **锁屏样式受系统限制**：是否显示大封面、显示哪些按钮由 ROM 决定。
- **部分音源只有试听片段**：属音源限制，会更快触发自动连播。
- **左边缘手势冲突**：从屏幕最左侧（系统返回区）起滑会被系统接管，从内容区起滑正常。
