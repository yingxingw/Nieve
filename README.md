## 功能

### 音乐

- 全屏播放页：封面缩到左上角，主体让给跟随高亮、可点击跳转的歌词；底部是进度条与上一曲 / 播放暂停 / 下一曲
- 悬浮唱片：离开音乐页后，播放中的歌收成左上角圆形唱片，播放时旋转、暂停即停，可拖动吸附边缘，旁边跟随当前一句歌词，点击回到播放页
- 三种播放模式：单曲循环、列表循环、随机播放，播放页与系统通知都能切换
- 歌单：新建、重命名、删除、增删歌曲、调整顺序，本地持久化，重启不丢
- 本地音乐：按文件夹或单曲导入设备音频，适配分区存储，不申请多余权限
- 系统媒体控制与锁屏：通知栏 / 媒体栏 / 锁屏显示封面、歌名、歌手与播放控制，与 App 内状态双向同步；停止播放会释放会话
- 音乐解析：独立板块，支持歌单 / 单曲链接解析、勾选批量下载、音质选择与来源切换，覆盖歌曲宝、酷狗音乐、网易云音乐、QQ 音乐、酷我音乐

### 工具中心

- 扫一扫 / 二维码：相机扫码、相册识别、多类型二维码生成
- 便签：本地存储、标签分类、搜索排序
- 倒数日：纪念日、按年 / 按月重复、系统通知
- 6 个实用小工具：Base64 编解码、摩斯电码、金额大写、时间戳转换、温度换算、特殊文字，均为纯本地计算
- 修改步数：Zepp 多账号、今日步数校准
- 七猫小说：榜单、搜索、在线阅读、整本下载
- 影视大全：多线路检索、详情、选集播放，播放页支持倍速、画面比例、循环、画中画、定时关闭与锁屏
- VIP 解析：内置小T（腾讯视频）、小Q（爱奇艺）、小B（哔哩哔哩）、小Y（优酷）桌面站，影院式海报列表，可缩放、收藏、切换线路；播放失败可交给浏览器打开
- 网页源码抓取：输入网址查看页面源码
- 随机视频：随机刷取短视频内容
- 自动领红包：本期不再提供，入口保留为原因说明页

### 解析与下载

- 网盘分享链接识别与提取码匹配：夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 光鸭 / 蓝奏云 / 蓝奏云优享版
- 视频 / 图集链接解析：抖音 / 小红书 / 快手 / 微博 / AcFun / 哔哩哔哩 / Pixiv
- 分片并发下载、断点续传、HLS / DASH、图片 / 视频 / 音频在线预览
- 多网盘账号管理、深链接 / 系统分享 / 磁力直链接入
- 浏览解析结果时侧栏自动收起，内容占满宽度；从内容区右滑以悬浮层呼出导航
- 启动 / 回到前台自动识别剪贴板链接，弹窗提供「一键解析」，直链与磁力可「直接下载」，同一链接按内容 hash 记忆不重复提示

### 自动跳过

- 无障碍服务自动点击开屏广告「跳过」按钮
- 云端规则同步、应用白名单、跳过检视、保活引导与本地日志

### 界面

- 液态玻璃外壳：浮动底栏、玻璃卡片、自绘分段导航
- 主题六档、Monet 取色、毛玻璃 BarBlur、动态背景着色
- 全项目统一动效：切换、选中、展开收起使用同一套过渡
- 流畅模式：自动按 `isLowRamDevice` 判断，也可手动开关（更短页面过渡、唱片停转、歌词与进度降频轮询、封面小尺寸解码、更低图片缓存上限、WebView 单实例且不落盘缓存）

### 远程能力

- 公告：应用内查看维护消息与版本提示
- 远程停用与强制更新：由维护者按版本统一控制
- 检查更新：应用内检查是否有新版本
- 网络不可用时按正常可用处理，不会因为拉取失败把应用锁死

## 构建

需要 JDK 21 与 Android SDK（platform 37.0 / build-tools 37.0.0）。

```bash
./gradlew :yunx:assembleDebug
# 产物：yunx/build/outputs/apk/debug/yunx-debug.apk
```
